Optional per-rule template override for the Build Failed event (token-macro syntax). Leave blank to fall back to the global default, then the built-in default.

Prefer the plugin's escaped ${SLACK_*} macros — their values are escaped for Slack mrkdwn, so a crafted branch/commit value cannot inject <url|label> link markup: ${SLACK_GIT_BRANCH}, ${SLACK_GIT_COMMIT}, ${SLACK_DEPLOYER}, ${SLACK_DURATION}, ${SLACK_BUILD_URL}.

Avoid raw ${ENV,var="..."} for SCM/PR-derived values (e.g. GIT_BRANCH, CHANGE_TITLE): those are inserted without Slack escaping and can carry injected link markup or leak sensitive build variables. A plain ${VAR} / $VAR that is not a recognized macro does not expand — the whole message is then sent as raw, unexpanded text.
